# Satoshi Node

Satoshi is the dedicated GhostNodes base node for a Bitcoin full or pruned node. It owns Bitcoin lifecycle, validation, storage sizing and its dedicated system service.

It supports arm64 and x86_64 profiles through the existing automated registry. An equipment installed as Halfin must not be converted into a Satoshi base node in place.

See [`docs/architecture/MONOREPO_TOPOLOGY.md`](../docs/architecture/MONOREPO_TOPOLOGY.md).
